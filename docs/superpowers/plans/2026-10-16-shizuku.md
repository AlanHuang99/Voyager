# Shizuku file access

Shizuku is an optional local access mode requested in #144. Settings opens a Shizuku connection dialog, requests authorization, and creates a separate session starting at shared storage's Android folder. Ordinary local, SAF, root, and remote sessions remain available.

The official Shizuku UserService API runs a non-daemon file-operation process. It passes command streams through file descriptors to the existing supervised shell provider, preserving quoting, staged writes, cancellation, timeout, and path-alias checks. The service accepts only its owning application or its own privileged UID. Its Binder is supplied by Shizuku and is not an exported Android service. A disconnected session reports failure and can be replaced after Shizuku restarts.

Access is the actual privilege of Shizuku: shell when started through ADB, root when started with root. Android/data and Android/obb are tested on the connected Android 16 K60. Access to other apps' private /data directories is not promised.
