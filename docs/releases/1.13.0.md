Voyager 1.13.0 adds Shizuku file access, shared-storage search, remote image thumbnails, and per-file menus.

- Open a separate Shizuku session from Settings to manage files with the connected service's shell or root privileges.
- Search filenames across accessible mounted shared storage from Home, then open a result or its containing folder.
- Show bounded image thumbnails for SFTP, FTP, SMB, and WebDAV files.
- Use per-file menus in List and Compact views for file operations and details.
- Preserve recovered archive output when extraction encounters unreadable entries, report renamed filename clashes, and write files concurrently during local extraction.
- Keep WebDAV playback active while Voyager is in the background, preserve playback URI identity when reopening a file, and retry interrupted byte-range reads.

Requires Android 8.0 or later. The universal APK supports all included architectures. GitHub and F-Droid use the same developer signing key; F-Droid publishes after its independent build and verification process.
