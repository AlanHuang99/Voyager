Voyager 1.14.0 adds saved Quick Access sorting and local Hide/Unhide actions.

- Sort Quick Access categories by name, size, modification date, or type in either direction. The setting persists independently from browser sorting and applies while files are being scanned.
- Hide and unhide local files and folders from their row menus or single-selection menu, including Grid. Use Show hidden files to reveal hidden entries.
- Update translations from the Voyager Crowdin project.

Requires Android 8.0 or later. The universal APK supports all included architectures.
