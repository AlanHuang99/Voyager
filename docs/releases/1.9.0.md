Voyager 1.9.0 adds file discovery tools, improves transfers and browsing, and introduces community translations.

- Browse storage categories and find duplicate files by content, with explicit selection and revalidation before removal.
- Pin local folders to the Home screen, remove bookmarks from the browser, and set audio files as ringtone or notification tones.
- Keep transfers running in the background, cancel supported operations, and resolve destination conflicts with Replace, Skip, or Cancel.
- Fix FTP metadata used by cross-location copies and moves, improve SMB compatibility, and open seekable WebDAV documents without downloading the entire file first.
- Improve external-editor saves, pull-to-refresh, drag selection, media previews, and saved SFTP host-key management.
- Add French and Simplified Chinese translations and a public [Crowdin project](https://crowdin.com/project/voyagerandroid) for translation contributions.
- Add explicitly confirmed root sessions and a guarded UTF-8 text editor for compatible devices with authorized superuser access.

Root access remains experimental: privileged operations were tested in an isolated Linux fixture, while the Android device checks covered cancellation, permission denial, and unprivileged command compatibility. Successful privileged Android operation remains unverified. Root operations bypass Trash.

Requires Android 8.0 or later. Choose the universal APK unless you need a particular architecture. Existing installations can update using an APK signed with the same release key.
