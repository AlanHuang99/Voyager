Voyager 1.16.0 adds archive formats and Android TV launcher support, and updates Shizuku folder browsing.

- Extract XZ, LZ4 and Zstandard files, including their TAR variants. Invalid compressor footers and oversized XZ dictionaries are rejected.
- List folders and resolve paths directly in the Shizuku service, with bounded metadata responses, cancellation and session recovery.
- Launch Voyager from Android TV and Google TV home screens.
- Scroll the final file row above the create button in List, Compact and Grid. Empty fields wait for editing before showing validation errors, and the create button follows the clipboard bar as it closes.
- Add partial Russian and Turkish translations with English fallback for missing text. Update German and Italian translations, including archive counts and Shizuku permission wording.

Requires Android 8.0 or later. The universal APK supports all included architectures.
