Voyager 1.15.0 adds incoming file sharing and combined file and folder search.

- Receive files through Android's share sheet, choose a local folder, document tree, or remote destination, and tap Save here. Transfers retain source access while running and release it after completion or cancellation.
- Find files and folders across accessible mounted shared storage. Open folder results directly or expand the browser's current query through Search shared storage.
- Transfer regular files through the Shizuku service using direct file I/O. Interrupted, cancelled, or abandoned writes discard their temporary stage.
- Correct Traditional Chinese translations through Crowdin and update German and Italian strings.

Requires Android 8.0 or later. The universal APK supports all included architectures.
