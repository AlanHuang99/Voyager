Voyager 1.10.0 improves browsing, selection, and archive extraction.

- Keep a single item selected when the selection toolbar moves the file list. Range selection and edge scrolling begin after an intentional drag.
- Use the Voyager icon on the splash screen and follow the system dark-mode background.
- Choose the existing top search field, compact toolbar search, or a bottom search field in Settings.
- Bookmark a selected local folder, pin its shortcut, or find duplicates using the same actions available inside that folder.
- Open saved connections, recent bookmarks, and mounted storage directly from the browser’s Sessions sheet. Existing sessions remain available, and the sheet includes a Home action.
- Restore directory scroll positions when returning to a parent or switching sessions, and preserve them when refreshing. Unrelated preference changes no longer reload the current directory.
- Avoid listing an extraction folder again for every archive entry while retaining normalized-path, duplicate-entry, and exact-name checks.

Existing bookmarks and connections are preserved when upgrading. New UI strings use English fallbacks until translations are available through [Crowdin](https://crowdin.com/project/voyagerandroid). Root access remains experimental; successful privileged Android operations remain unverified.

Requires Android 8.0 or later. The universal APK works across supported architectures and can update existing installations signed with the same release key.
