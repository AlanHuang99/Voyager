Voyager 1.11.0 expands translations and adds links for community corrections.

- Add provisional translations for Simplified Chinese, Traditional Chinese, Spanish, French, German, Brazilian Portuguese, Japanese, Korean, Italian, and Vietnamese.
- Open the matching Crowdin language page from Settings > About > Help improve translations.
- Show a dismissible translation notice on Home. Dismissal is remembered separately for each language, and the Settings link remains available.
- Preserve existing translations and use English fallbacks where sensitive messages have not been reviewed or translations are missing.
- Correct file-manager terminology in translated controls, including archive extraction, paths, and transfer status.

Translations include machine-generated drafts and still need language review. Contributors can suggest corrections on [Crowdin](https://crowdin.com/project/voyagerandroid); approved corrections are included through subsequent app releases.

Requires Android 8.0 or later. The universal APK works across supported architectures and can update existing installations signed with the same release key. Root access remains experimental; successful privileged Android operations remain unverified.
