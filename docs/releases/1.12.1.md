Voyager 1.12.1 fixes SMB connection recovery and ZIP creation for large files.

- Restore SMB browsing after a cached share or connection closes, allowing Reload to reconnect.
- Add ZIP64 support for files listed at 4 GiB or larger.
- Correct surface container colors in built-in themes.
- Update German and Italian labels.

Requires Android 8.0 or later. The universal APK supports all included architectures. GitHub and F-Droid use the same developer signing key; F-Droid publishes after its independent build and verification process.
