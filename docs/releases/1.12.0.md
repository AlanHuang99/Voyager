Voyager 1.12.0 improves search, remote downloads, duplicate scans, archive operations, and root browsing.

- Fix keyboard layout when the search bar is at the bottom of the browser.
- Ask before downloading files tapped on SFTP, FTP, and SMB servers. Settings can restore immediate downloads.
- Exclude recycle folders from duplicate scans by default and allow editing the folder-name exclusions.
- Add archive progress and cancellation, including cleanup of partial output when an operation is cancelled.
- Use the global mount namespace for root sessions, fixing browsing on KernelSU Next devices affected by mount isolation.
- Include the contributed Italian translation corrections.
- Simplify the README and add a contributor guide covering Crowdin, bug reports, code, and device testing.

Requires Android 8.0 or later. The universal APK supports all included architectures. GitHub and F-Droid use the same developer signing key; F-Droid publishes after its independent build and verification process.
